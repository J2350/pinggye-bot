# 핑계봇

출근길에 지각하게 됐을 때, 상사에게 보낼 **예의 바른 사과 메시지**를 AI가 1분 안에 만들어 주는 웹 앱입니다.

교통수단, 늦는 시간, 상사와의 관계만 고르면 그 상황에 맞는 메시지가 나옵니다. 마음에 안 들면 다른 핑계로 다시 만들고, 버튼 한 번으로 복사해서 메신저에 붙여 넣으면 됩니다.

## 이렇게 씁니다

1. 교통수단(지하철·버스·자가용·택시·도보)을 고릅니다.
2. 늦는 시간을 분 단위 숫자(1~180)로 입력합니다.
3. 상사와의 관계(격식 / 편한 사이)를 고릅니다.
4. **핑계 만들기**를 누르면 메시지가 나옵니다.
5. 마음에 안 들면 **다시 만들기**(한 상황에서 최대 5번), 마음에 들면 **복사**를 누릅니다.

## 만들어지는 메시지의 규칙

- 3문장 이내, 공백 포함 100자 이내
- 고른 교통수단과 늦는 시간("20분")을 그대로 포함
- 격식이면 "-습니다"체, 편한 사이면 "-요"체
- 사과 문장을 반드시 포함하고, 도착 시각 대신 늦는 시간으로 알림
- 큰 질병·큰 사고·가족 사망 같은 거짓이면 문제가 커지는 핑계는 쓰지 않음
- 다시 만들 때는 직전 3개와 다른 사유를 사용

AI가 규칙을 어기면 서버가 검사해서 한 번 더 만들고, 그래도 안 되면 "잠시 후 다시 눌러 주세요"를 보여 줍니다.

## 기술

- Next.js (App Router) · TypeScript · Tailwind CSS
- OpenAI API (`gpt-4.1-mini`) — 서버에서만 호출
- three.js — 밤 꽃 계곡 3D 배경
- Vercel 배포

## 안전하게 만든 점

- API 키는 서버 코드에서만 읽고 브라우저로 나가지 않습니다. (`lib/ai.ts`는 `server-only`)
- 사용자가 자유롭게 쓰는 글이 없습니다. 모든 입력은 정해진 선택지나 숫자로 검사한 뒤에만 AI 지시문에 들어갑니다.
- 로그인·데이터베이스·쿠키가 없고, 입력 내용을 저장하지 않습니다.
- 서버에 요청 제한이 있습니다. (접속자당 1분 10번·1시간 60번, 다른 사이트에서 온 요청·JSON이 아닌 요청·큰 요청 거절)

## 직접 실행해 보기

```bash
npm install
```

프로젝트 폴더에 `.env` 파일을 만들고 본인의 OpenAI API 키를 넣습니다. (이 파일은 git에 올라가지 않습니다.)

```bash
OPENAI_API_KEY=여기에_본인_키
```

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 글을 만들 때마다 본인 OpenAI 계정에서 소액이 청구됩니다.

```bash
npm run lint
npm run build
```

## 폴더 구조

```
app/                 화면(page.tsx)과 서버 창구(api/excuse/route.ts)
components/          입력 폼·결과·3D 배경 화면 조각
lib/constants.ts     교통수단·제한값 등 공통 약속
lib/validate.ts      입력 검사와 메시지 규칙 검사기
lib/prompt.ts        AI에게 주는 지시문
lib/generate.ts      만들기 + 규칙 검사 + 1회 재시도
lib/ai.ts            OpenAI 연결 (서버 전용)
lib/guard.ts         요청 제한과 요청 검사
```
